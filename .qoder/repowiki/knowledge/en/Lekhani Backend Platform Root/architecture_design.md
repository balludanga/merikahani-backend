The root is an orchestrator rather than application code: it declares the shared dependency surface in `requirements.txt` (FastAPI, SQLAlchemy+psycopg2, Pydantic v2 via pydantic-settings, JWT via python-jose, bcrypt) that both the `app` package and the `tests` package consume. Runtime entry points are defined uniformly as `uvicorn app.main:app --host 0.0.0.0 --port <port>` across three deployment targets — the standalone `Dockerfile`, the local `docker-compose.yml` (which also mounts `./app.db` for SQLite persistence and source for hot reload), and `render.yaml` (which provisions a PostgreSQL database named `lekhani-db` and injects its connection string via `fromDatabase`). Configuration flows through `pydantic-settings` reading `.env`-style variables (`DATABASE_URL`, `SECRET_KEY`, `ALGORITHM`, `ACCESS_TOKEN_EXPIRE_MINUTES`, `GOOGLE_CLIENT_ID`, `FRONTEND_URL`, `CORS_ORIGINS`, `ENVIRONMENT`) declared in `.env.example`. The `tests` package exercises the same `app.main:app` ASGI application via FastAPI's `TestClient`, so there is no separate test server process.
