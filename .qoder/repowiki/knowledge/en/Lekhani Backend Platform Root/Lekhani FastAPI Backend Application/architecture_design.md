app/main.py is the single entry point: it creates the SQLAlchemy engine, calls Base.metadata.create_all() plus a runtime ALTER TABLE migration for posts, then instantiates the FastAPI app, registers CORSMiddleware plus two custom ASGI middlewares (COOP header injection and private-network preflight), and mounts all domain routers under /api via api_router. Each child module owns one FastAPI Router mounted at a sub-path; routers consume shared infrastructure from app.core (settings, security helpers, dependency providers) and share persistence through the SQLAlchemy models in app/models/ plus the database engine in app/database.py. Schemas in app/schemas/ define Pydantic request/response types consumed by multiple endpoints. Cross-child coupling goes only through these shared layers — routers do not import each other.
