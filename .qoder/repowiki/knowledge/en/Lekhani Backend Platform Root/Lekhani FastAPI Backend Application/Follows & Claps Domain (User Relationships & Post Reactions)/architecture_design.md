Two-layer leaf module: a FastAPI router (`app/api/endpoints/follows.py`) exposing REST routes for following, unfollowing, listing followers, and listing who a user follows, plus two SQLAlchemy ORM models (`app/models/follow.py` → `follows` table, `app/models/clap.py` → `claps` table). The endpoint layer depends on shared infrastructure — `app.database.get_db`, `app.core.dependencies.get_current_user`, `app.models.user.User`, and `app.schemas.user.UserResponse` — but the model layer has no inward dependency on the API. Both models extend `app.database.Base` and enforce uniqueness at the DB level via `UniqueConstraint` (`uq_follow_follower_following`, `uq_clap_user_post`). Follow queries use explicit `db.query(...)` joins between `User` and `Follow`, while clap is modeled as an aggregate count per user-post pair rather than a boolean toggle.
