Two parallel FastAPI `APIRouter` modules (`comments.py`, `tags.py`) expose REST endpoints that depend on shared infrastructure: `app.database.get_db` for a SQLAlchemy `Session`, `app.core.dependencies.get_current_user` / `get_current_user_optional` for auth, and Pydantic schemas under `app.schemas.*`. The data layer is defined in `app/models/comment.py` (a `Comment` model with FKs to `posts` and `users`, plus bidirectional relationships) and `app/models/tag.py` (a `Tag` model with a many-to-many `post_tags` association table exposing `Tag.posts`). Endpoints query via the ORM directly rather than through a repository layer. Tag endpoints additionally join `Post.published == 1` and enrich returned posts with per-user clap counts and bookmark flags when an optional authenticated user is present.
