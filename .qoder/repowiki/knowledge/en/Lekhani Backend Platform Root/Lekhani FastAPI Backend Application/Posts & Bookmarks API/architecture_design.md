Two FastAPI `APIRouter` modules (`posts.py`, `bookmarks.py`) expose REST endpoints over the `Post` and `Bookmark` SQLAlchemy models. The post router owns full CRUD plus a `/clap` action; the bookmark router only lists a user's bookmarks and add/remove them. Both routers depend on shared infrastructure: `app.database.get_db` for sessions, `app.core.dependencies.get_current_user[_optional]` for auth, and schemas from `app.schemas.post`. Cross-entity state (viewer clap count, bookmarked flag) is attached to returned `Post` objects via the in-module `decorate_posts` helper rather than through ORM relationships, keeping response augmentation separate from persistence. Tag normalization and slug generation are local helpers within `posts.py`; tag resolution goes through the `post_tags` association table defined elsewhere. Bookmark uniqueness is enforced at the DB level via a `UniqueConstraint` on `(user_id, post_id)`.
